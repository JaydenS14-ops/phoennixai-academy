# Private Admin Access Notes

Keep this document for authorised Academy administrators. Do not link it from public navigation or public page content.

## Admin login

Open `https://phoennixai-htyubyfb.manus.space/admin/login` on any phone, tablet, or computer. Admin access remains protected by the existing username and password flow.

## Keyboard shortcut

On a physical keyboard, press **Ctrl + Shift + A** on a public page to open the Admin login portal. The shortcut is intentionally ignored while focus is inside an input, textarea, select, or content-editable control.

## Mobile bookmark

On iPhone or iPad, open the Admin login URL in Safari, select **Share**, then choose **Add to Home Screen**. On Android, open the URL in Chrome, select the browser menu, then choose **Add to Home screen** or **Add bookmark**.

This guide contains no administrator credentials. Credentials must remain in the secure project configuration and must never be committed to source control.
