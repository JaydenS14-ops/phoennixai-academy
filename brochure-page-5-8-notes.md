# Brochure Pages 5 to 8 Notes

This review is being used to refine the public visual system. The relevant direction from pages 5 to 8 should influence the next design pass in three ways.

First, the events experience should no longer reuse the homepage hero. A distinct secondary brochure image from this section should be used to give the events page its own identity.

Second, the fantasy layer should become more visible through composition rather than through generic decorative icons. The public pages should use image-led sections, controlled depth, luminous overlays, and a stronger phoenix-inspired visual rhythm.

Third, the brochure section should guide the public layout toward clearer narrative variation between homepage, programmes, and events so each screen feels intentionally art-directed rather than repeated.
